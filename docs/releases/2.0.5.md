# EnCap 2.0.5

This release includes the updated Video export interface: chapter selection and advanced format and artwork controls can be collapsed, with a short summary visible while closed. Export controls remain visible.

The six downloads were built and tested by the native platform workflow from this tag. Each download has a SHA-256 entry in `SHA256SUMS` and a GitHub artifact attestation.

**Distribution limitations:** The macOS ZIPs are ad-hoc signed and have not been Developer ID signed or notarized. The Windows ZIPs are not Authenticode signed. Native installation and upgrade acceptance have not been completed for these exact packages. No signed update manifest or macOS appcast is included, so this release is available by manual download only. macOS Gatekeeper or Windows SmartScreen may warn when opening the application.
