# EnCap 2.0.6

This patch release incorporates checked multiplication and bounds handling in the vendored miniaudio playback code. It also fixes the ALSA compilation regression found while verifying those changes on Linux. Native regression coverage exercises representative overflow boundaries.

Each platform download is published independently after its native build, media and runtime checks, package integrity check, and application launch or equivalent smoke test pass. Each package includes the pinned, authenticated AVID Core FFmpeg/ffprobe runtime and a SHA-256 sidecar. GitHub records package provenance attestations where available.

The macOS ZIPs are ad-hoc signed and are not Developer ID signed or notarized. The Windows ZIPs are not Authenticode signed. No signed update manifest or macOS appcast is generated for these direct downloads; authenticated automatic-update verification remains enforced. Manual installation and upgrade acceptance on every target have not been completed.
