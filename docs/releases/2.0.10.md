# EnCap 2.0.10

This source release updates both EnCAP's Rust media dependency and its bundled
Swift transcription libraries to AVID Core 0.3.2 at immutable commit
`8296a9e623c6924c12e456b5fe9e7c10b59dfbde`.

- Video receives Core's square-pixel normalization for mixed-aspect portrait
  timelines and its GIF/APNG rendering fixes. Automatic rendering retains
  animated artwork; Simple rendering deliberately freezes it.
- The shared transcription store receives upstream lifecycle and model-import
  fixes. The 34-file Swift snapshot, archive, manifest, sidecar provenance and
  verifier hashes move together; third-party SDK revisions remain pinned.
- Core's exact zopfli 0.8.2 dependency is retained in the lockfile. Native image
  codecs compile from pinned source using a C compiler and CMake. Their full
  license texts and Independent JPEG Group attribution travel with packages.
- The authenticated FFmpeg/ffprobe runtime and update-signature contracts remain
  pinned independently of the Core source version.

## Verification and release scope

Core's portrait and GIF/APNG real-media regression tests passed against EnCAP's
authenticated macOS ARM64 FFmpeg/ffprobe pair. The refreshed shared Swift package
passed 32 tests. EnCAP build, package and integration results are recorded with
this task's local verification evidence.

This is a source tag and push. No binary assets or authenticated update metadata
are published by this operation. Local macOS verification does not qualify Intel,
Windows or Linux packages. The owner-directed weekly smoke workflow remains
scheduled only; tags do not trigger CI, and archived workflows remain disabled.
