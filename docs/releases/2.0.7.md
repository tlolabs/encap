# EnCap 2.0.7

This release delivers the completed and independently audited migration of the shared desktop frontend from Avalonia/.NET to native Qt 6 Widgets across Windows (x64 and ARM64) and Linux (x64 and ARM64), alongside an internal macOS ARM64 Qt reference application. The production macOS desktop application remains native SwiftUI/AppKit.

Key migration and audit deliverables in 2.0.7:
- Complete removal of Avalonia, C#, .NET, MSBuild, and NuGet tooling and dependencies. The application builds without the .NET SDK.
- Shared Qt 6 Widgets client linking `Qt6::Core`, `Qt6::Gui`, and `Qt6::Widgets` under GPL-3.0-only terms with corresponding source tracking.
- Native playback adapter utilizing reviewed miniaudio with checked bounds and format fallbacks.
- Platform-native media integration: Windows System Media Transport Controls (SMTC) and Linux MPRIS D-Bus.
- New pure-Rust Windows portable updater (`encap-portable-update`) with atomic journaled replacement and rollback.
- Corrected engine and client boundary defects including safe signal cancellation, robust environment test overrides, and chapter selection consistency.
- Preservation of authenticated AVID Core FFmpeg/ffprobe runtime integration and pinned Whisper models.

Each platform download is published independently after its native build, media and runtime checks, package integrity check, and launch smoke test pass. Packages include SHA-256 sidecars and provenance attestations where available.

## macOS artwork controls

- Click the album artwork file area to switch between its filename (the default) and full path, including the filename.
- Drop an image file onto the album artwork row or preview to replace the artwork.
- Chapter artwork icons accept dropped image files. Selected artwork also has a clickable filename/path label beside the icon.
- Invalid or unreadable image files leave the existing artwork unchanged.

## Published package

This release publishes the locally built Apple silicon macOS package, signed with Developer ID, notarized by Apple, and stapled. The ZIP has a SHA-256 checksum sidecar. Other platforms are not included in this local release.

Builds, package integrity and runtime checks, media import/save/export checks, and launch verification run locally. No GitHub Actions runners are used for this release. This is a direct-download release; authenticated update feeds are not changed.
