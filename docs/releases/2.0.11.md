# EnCap 2.0.11

This release updates Rust AVID Core to **0.3.3**, pinned to immutable commit
`8e27a86ec106028d93130de35a35c0eeda7a9ce3`. The independently verified Swift
transcription source remains pinned to 0.3.2; its Apple sources are unchanged
between these Core releases. The authenticated FFmpeg runtime pin is unchanged.

- Added **Optimize Copy…** for episode artwork in the macOS and Qt clients,
  using Core's lossless JPEG/PNG optimization and metadata removal. Originals
  and project/source paths are protected. Removing orientation/color metadata
  can change how a viewer displays the copy.
- Ordinary supported-host SRT and CLI WebVTT export now use Core's cue exporter,
  preserving segment boundaries and speakers. Core's markup escaping, newline
  folding and stricter ordered, positive-duration cues are intentional changes.
- Pending artwork dialogs/results are bound to their original project, avoiding
  changes to another window's newly opened project.
- Standard local Mac distribution requires Developer ID signing and notarization.
  The signer refreshes transcription qualification after nested signatures, so
  the packaged evidence matches the final engine/helper/resource bytes.
- Local builds and the existing weekly smoke job use Rust 1.99.1. The Sunday-only
  schedule and disabled archived workflows remain unchanged.

## Scope and remaining limits

This operation provides the local notarized Mac ZIP and a source commit/annotated
`v2.0.11` tag. It does not upload binary release assets or publish update feeds.
Existing authenticated update checks are preserved.

The base app targets macOS 13; new inference and Core subtitle formatting require
Apple silicon/macOS 14+. Intel, Windows and Linux packages were not built or
qualified here. Existing saved SRT remains available on unsupported Core platforms.
Audio-only export/PCM decoding, sample/waveform inspection and portable subtitle
APIs remain documented Core gaps. Interactive UI, authenticated upgrade and
multilingual/long-form accuracy were not qualified by this local smoke test.
