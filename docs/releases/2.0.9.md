# EnCap 2.0.9

This release integrates AVID Core 0.3.1 at immutable revision
`15f28236142c100d0a83bf19154ed6f9f5b44e75` and includes the accumulated source
and documentation changes from the local workspace. User recordings and the
local `.encap` project are excluded from the source release.

- Video artwork inspection, PNG composition previews in macOS and Qt, and exports
  use Core's public renderer. Reusable sessions retain Core's probe caches.
- Confirmed static PNG/JPEG timelines use cached-frame Simple rendering within a
  conservative memory budget. Animated/unknown artwork and larger timelines
  retain PerFrame. Execution-only comparison controls preserve saved settings.
- Independent cancellation, bounded cross-process concurrency, serialized output
  writers, protected source/project paths, and publication confirmation preserve
  existing outputs on failed or cancelled operations.
- The release also includes pending Audio/Transcript, project handling, native
  playback, and UI fixes, together with local verification and Actions audit
  documentation. Existing project formats and authenticated runtime/update
  verification remain compatible.

## Download and verification

The Apple silicon macOS ZIP is built locally, Developer ID signed, notarized by
Apple, stapled, and verified from the final extracted archive. Gatekeeper accepts
it as Notarized Developer ID. A SHA-256 sidecar accompanies the ZIP. Other
platform packages are not included because they were not built and functionally
verified for this release.

Local checks passed: workspace release builds, formatting, Clippy, 104 Rust
tests, 38 native Swift tests, and all seven packaged Audio/Transcript/Video media
contracts. Runtime relocation, damaged-tool rejection, project save/audio-edit
protocols, archive integrity, and native app launch were verified. The ordinary
Rust suite has 13 opt-in tests ignored; native engine and renderer tests were
also exercised separately as described in the integration report.

## Known Core limits

Two native renderer tests remain diagnostic failures: some mixed-aspect portrait
timelines fail with mismatched sample aspect ratios at concat, and valid GIF
artwork fails in the existing PerFrame path with `Option loop not found`.
Existing output files remain unchanged in both cases. Five supported
Simple/PerFrame comparison pairs produce identical decoded pixels, audio, and
timestamps. See the [integration report](../core-031-integration.md) and
[native evidence](../verification/core-0.3.1-native.json).

This is a direct-download release. No GitHub Actions are used for this build or
qualification. Authenticated updater feeds and macOS appcasts are unchanged;
no new update metadata is published.
