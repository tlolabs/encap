# EnCap 2.0.8

This macOS release reorganizes the workspace header and Video editor.

- One header keeps the sidebar toggle, Import Audio, Open Project, Save Project, Mode selector, and the current mode’s labeled export action together.
- Export Audio, Export Video, and Export Transcript each appear in the same top-right position in their respective modes.
- Native window controls remain visible when switching modes. Import, Open, and Save use plain SF Symbols with consistent sizing and alignment.
- Video has a collapsible chapter sidebar with inclusion checkboxes, drag reordering, and Move Up/Down controls. Video ordering remains independent of the audio chapter order.
- Video settings and timeline preview have room for their labels. Advanced format and Artwork and preview start expanded.

## Download and verification

The published download is the Apple silicon macOS ZIP, built locally, signed with Developer ID, notarized by Apple, and stapled. A SHA-256 checksum is provided. Other platform packages are not included in this release.

Compilation, native regression tests, bundled runtime/dependency validation, media import/save/export checks, package integrity, and launch smoke verification run locally before publication. No GitHub Actions runners are used. This is a direct-download release; authenticated update feeds are unchanged.
