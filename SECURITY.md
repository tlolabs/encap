# Security policy

## Supported versions

Security fixes target the latest stable release and current `main`.
Older releases and development builds are not guaranteed security updates.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/tlolabs/encap/security/advisories/new)
as the primary channel; it is enabled for this repository. Do not disclose an
exploitable issue in a public issue. If private reporting becomes unavailable,
open a non-sensitive issue asking for private contact. Public security email:
**TBD**.

Include affected versions, reproduction steps, impact, and a safe proof of
concept. Thomas Lothian will acknowledge the report, investigate privately,
coordinate a fix and release, and credit the reporter if desired. Please allow
time for a fix before public disclosure; no fixed response or embargo period
is promised.

Official security fixes are published through
[GitHub Releases](https://github.com/tlolabs/encap/releases).
