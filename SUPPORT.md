# Support

- **Bugs:** Open a [bug report](https://github.com/tlolabs/encap/issues/new/choose)
  with the EnCap version, platform, steps, and relevant local logs.
- **Feature requests:** Open a feature request with the use case.
- **Usage questions:** Use GitHub Issues and describe what you tried.
- **Security vulnerabilities:** Follow [SECURITY.md](SECURITY.md); do not post
  exploit details publicly.

This is a community-maintained open-source project. Support is best effort.
