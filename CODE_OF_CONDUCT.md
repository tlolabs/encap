# Contributor Covenant Code of Conduct

This project adopts the [Contributor Covenant 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/).
Participation in issues, pull requests, and project discussions is expected
to follow that published code of conduct. Be respectful, avoid harassment and
discrimination, and help keep project spaces welcoming and safe.

Thomas Lothian is responsible for enforcement. For a conduct concern, request
private contact in a non-sensitive GitHub issue; do not publish personal
information or detailed allegations publicly. A dedicated public contact
address is **TBD**. Reports will be considered privately and handled in line
with the Contributor Covenant's enforcement guidance.
